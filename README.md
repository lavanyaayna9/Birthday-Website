# Birthday Website

A responsive birthday-themed website built using HTML, CSS, and JavaScript.

## Features

* Responsive layout
* Interactive photo memories section
* Personalized birthday message
* Confetti celebration animation
* PDF letter download functionality
* Mobile-friendly design

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Canvas Confetti
* jsPDF

## Setup

1. Clone the repository.
2. Open `index.html` in a browser.
